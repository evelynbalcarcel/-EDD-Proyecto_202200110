# EDD Proyecto — Social Structure

Proyecto de **Laboratorio de Estructura de Datos (EDD)**, desarrollado por **Evelyn Maricely Balcarcel Rivera** (202200110), Ingeniería en Ciencias y Sistemas — USAC, 2.º semestre 2024.

## Descripción

**Social Structure** es una aplicación que simula una red social. Permite a los usuarios registrarse, iniciar sesión, gestionar solicitudes de amistad, crear publicaciones y generar reportes. Incluye un módulo de administrador para la carga y gestión de datos.

El proyecto se implementa en tres fases progresivas:

- **Fase 1** — Aplicación de consola en C++ con estructuras de datos fundamentales.
- **Fase 2** — Interfaz gráfica con Qt, incorporando árboles AVL y listas enlazadas.
- **Fase 3** — Extensión del proyecto .

## Estructuras de datos

- Lista doblemente enlazada de usuarios
- Pila y lista para solicitudes de amistad
- Matriz de amistad entre usuarios
- Árbol AVL para búsqueda eficiente de usuarios (Fase 2)
- Listas enlazadas para publicaciones y comentarios
- Persistencia de datos en archivos JSON

## Tecnologías

- C++
- Qt / QMake (Fase 2)
- nlohmann/json
